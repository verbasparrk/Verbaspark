# Verbaspark

A personal-page editor with Bento, Classic, Editorial, Showcase, and other visual layouts. Run `npm install` then `npm run dev`. Create a production build with `npm run build`. See [SETUP.md](SETUP.md) for Supabase accounts, private drafts, image storage, and public page publishing, and [VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md) for Vercel deployment. GitHub verifies unit, browser, and mocked-cloud tests plus the production build on each push and pull request.

Explore templates opens Creator, Professional, and Personal starters with a live preview. By default, applying one keeps existing content and images while updating styling, order, and sizes. Uncheck Keep my existing content to start from the sample page instead. Applying a template is a single undoable change; previews and closing the picker do not modify the page.

Add a link (also available through Blocks → Link) offers Website, Instagram, LinkedIn, GitHub, Spotify, Portfolio, YouTube, other videos, and Email. Enter a destination and optional description; bare domains are normalized to HTTPS and email addresses to mailto links. Each creates an editable card. These are outbound links, not connected social accounts or embedded players.

Blocks → Gallery supports up to 12 photos with batch upload, captions, ordering and removal, a grid or horizontal slider, spacing and corner settings. Preview/public pages and HTML exports include a keyboard-accessible enlarged viewer (arrow keys, Escape). Storage capacity still applies. Explore templates also includes three fictional sample profiles: Photographer (Luka Novak), Developer (Nika Kovač), and Personal story (Maja Zupan), with stock images and example destinations. Apply without Keep my existing content to load the complete sample; Undo restores your page.

On phones, the page fills the workspace. The bottom toolbar opens Add and Design in a modal bottom sheet or switches to a clean preview. Tap a card to edit it; close settings with Done, Escape, the backdrop, or a downward swipe on the panel header. The top ellipsis menu contains account/publishing, templates, links, export, editor theme and undo/redo. Mobile editing uses the responsive layout automatically.

Explore templates includes **Digital business card**, a classic single-column profile with a cover photo, overlapping portrait, introduction, primary contact button, and optional content sections. Keep existing content to restyle your own page, or uncheck it for the complete fictional chef example. **Design → Page layout** switches between Classic profile and Bento grid without removing content. In Classic profile, photo settings offer Cover photo, Profile portrait, and Content photo placements; uploads and cropping work as usual. The introduction supports a profession/location subtitle and customizable button label. The header stays at the top; other sections can be reordered and fit their content automatically. Layout and photo placements persist in recovery/backups, online documents, and HTML exports. Location is an ordinary map link, not an embedded map. Contact buttons open email; no contact form or QR sharing is included in this template.

On desktop, the **My page** menu groups Account & publishing, Save & recovery, Explore templates, Export HTML, and Getting started; Publish opens account/publishing. The sidebar focuses on adding content and styling. Controls share one SVG icon set. Cards have content-aware grid heights, with an optional Compact height setting (contacts default to compact). Links support Icon, Card, and Wide appearances with recognizable platform icons. Template thumbnails render the actual sample pages. A dismissible four-step guide tracks adding a name, photo, link and opening Preview; it disappears once completed and can be reopened from My page.

Use Blocks to add content, Design for page styling, and Edit for the selected card. Select cards to edit their content, drag to reorder, or use Earlier/Later controls. Double-click text on a selected card to write directly; blur to save, Enter to finish a title, or Escape to cancel. Choose Small, Wide, or Tall, or drag the selected card's corner handle to resize. Design controls adjust the name, accent, spacing and corners. Preview enables links; Export page downloads a standalone HTML page.

Changes save on this device through IndexedDB, with a localStorage fallback and six recovery versions. The save indicator opens **Save & recovery** for retries, version restoration, JSON backup download/import, and resolving online draft conflicts. Signed-in private drafts autosave after editing once Supabase is configured. Interrupted sync resumes after reconnecting; publication always remains explicit. If device storage is full, edits remain open with a warning instead of being discarded. Undo/redo applies during the current session. Billing is not implemented. YouTube and Vimeo video cards have click-to-load players and an original-link fallback. External images and fonts require internet access. Cloud image URLs expire after one hour; reload the online page to renew them. HTML export embeds cloud photos so exported photos do not expire.

The top-bar sun/moon switch controls the editor appearance independently of the page. The Design tab offers light/dark page palettes, four presets, six editable colors, heading/body font families, typography sizing and weight, card spacing/padding/radius/borders/shadows, and solid or outlined buttons. These settings persist, support undo, and travel with HTML exports. Reset restores default page styling without deleting content.

Select a photo card to upload a JPG, PNG, or WebP (up to 15 MB), or drop a file onto its upload area or the selected card. Photos are compressed to WebP with a maximum dimension of 1600 pixels before local saving. Horizontal/vertical position and zoom controls adjust the crop live; alt text describes the image for screen readers. Uploaded images are embedded in HTML exports and need no external image hosting. Browser storage capacity limits the number of uploads; failed saves preserve the previously saved page.

Drag the selected card’s bottom-right handle to snap between Small, Wide, and Tall sizes. An outline previews the size before release; Escape cancels. With the handle focused, arrow keys change size (right: wide, down: tall, left/up: small). Reordering shows an in-grid placeholder; drop toward the bottom of a card to place after it. Each completed gesture creates one undo step. Mobile still uses the same responsive layout; separate mobile arrangements are not implemented.

Blocks now includes Document (PDF, DOCX, XLSX, PPTX, TXT), Catalog (PDF with optional uploaded cover), Audio (MP3, WAV, OGG, M4A), and Location. Uploads are limited to 20 MB each and the editor allows 50 MB of file attachments per page; the displayed usage counts uploaded attachments on the current page, not all retained cloud objects. Browser storage may be lower. Files stay in local recovery until online saving is configured. PDF opens in a dialog with a download fallback; office/text files download. Audio/video/maps load on request, never autoplay. Location accepts an address for navigation and optional latitude/longitude for an OpenStreetMap preview. Coordinates are entered explicitly, not geocoded. The Blocks panel can recognize an uploaded file or a pasted YouTube/Vimeo/direct-file URL. Direct remote file URLs must end in a supported extension. Remote servers can prevent previews or downloads; the original link remains available. Uploaded local files and accessible cloud attachments are embedded in HTML/JSON exports; linked external files stay external. Both Classic and Bento layouts support these blocks.
The **Blocks** tab opens a grouped Add content library on desktop and the same library in the mobile sheet. Each block has a description and example. Introduction, Photos, Documents, Media, and Contact & links group the options; file upload and URL recognition remain available in the expandable quick-add area. New audio/video/gallery/catalog blocks start wide; contacts and downloads start compact. Catalog editing includes a cover placeholder rather than a sample photograph.

The selected block's **Duplicate** action makes an independent copy immediately after the original; duplicated cover/portrait photos become ordinary content photos. **Hide from public page** keeps the block in the editor and private draft, including recovery and JSON backups, but excludes it from Preview and HTML export. Publish again to update the live page. Migration 005 also removes hidden content from the published JSON itself, so private text and attachment references are not sent to visitors. Existing signed attachment URLs may remain valid until their expiry.
**Review before publishing** is available from Publish and the My page/mobile menu. It checks visible blocks for missing uploads, empty galleries/text, invalid website/email destinations, missing location details, and example content. Blocking issues must be fixed; suggestions can be acknowledged. Clicking an issue opens the matching block and focuses its field. Hidden blocks are excluded. Publishing from Account also requires the review unless the exact current page was already reviewed. Checks validate local content and URL syntax; they do not probe remote URLs or guarantee delivery, playback, geocoding accuracy, or external availability. Online configuration and authentication are still required separately.
